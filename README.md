# 全场ETF资金监测看板

双击 `启动实时看板.bat`，浏览器将打开 `http://127.0.0.1:8765`。不要直接双击 `index.html`，盘中行情需要本地服务转发。

## 看板内容

- ETF盘中最新价、涨跌幅、成交量、成交额、规模及行情时间
- ETF申购赎回代理指标：基金份额变化、变化率、估算净申购/赎回金额
- 日、周、1个月、2个月、3个月、6个月、12个月、今年以来、自选区间、20240924-20260630（固定历史区间）周期切换；自选区间可指定任意起止日期（最早 2024-01-01），起止两端均取当日或之前最近披露日的份额
- 估算净申购与净赎回 Top 20、全量明细、名称或代码搜索
- 每个申购赎回周期以每日柱状图展示真实交易日净变化；金额随盘中价格每30秒动态重算
- ETF资金轮动：按互斥资产/行业方向汇总流入、流出及净流入，展示主要流入与流出方向排名，并随周期和盘中价格动态重算
- 沪深市场、重点宽基、申购赎回方向等筛选
- 重点宽基累计份额：把沪深300、上证50、中证500、中证1000、创业板指、科创50六个宽基指数各自全部跟踪ETF的披露份额合计，画成每日堆叠柱状图（每个交易日一根柱，自上而下按 沪深300、科创50、创业板指、上证50、中证500、中证1000 堆叠，图例同序），并可左右平移与缩放
- 重点宽基每日增减：同一面板内，用堆叠柱展示六个宽基每个交易日的份额增减，红柱为净申购、绿柱为净赎回，与累计图共用宽基勾选、日期窗、平移与缩放
- 科创板占比板块：按沪深300、上证50、中证500、中证1000的固定顺序，在同一图表中用四种颜色比较每日科创板权重占比，并展示每日明细、股票数量与权重前五名
- 创业板占比板块：按沪深300、深证成指、中证500、中证1000的固定顺序，同口径展示每日创业板权重占比（成分股代码 300/301/302 开头），结构与科创板占比板块一致

## 更新方式

- **一键重建**：`python rebuild.py`（实时快照 → 周期快照 → 每日变化 → 指数权重）；单步可 `python rebuild.py --only periods|history|weights`
- **数据复验**：`python verify_data.py`（离线自洽检查）；`python verify_data.py --online` 额外抽样回源核对
- 启动时自动更新ETF历史份额数据
- 首次启动会建立自 2024 年 1 月初以来的沪深交易所官方日频份额缓存（上交所缓存含 2023-12-22 起的前置基期，供 2024 年以来周期取基），之后仅补充新增交易日
- 网页中的“刷新盘中行情”更新价格、成交和规模快照
- 进入科创板占比（或创业板占比）板块时按所选周期加载四个重点宽基的对应板块成分股及指数未复权日线收盘价，用于每日占比回溯；历史收盘价落盘固定，后续只补充缓存区间前后缺失的交易日
- 上交所、深交所均使用交易所披露的ETF份额历史；缺失日期不补零、不插值
- ETF份额是交易所日频披露数据，不是逐笔盘中申购赎回数据；金额按当前盘中价估算

## 计算口径

- 份额变化 = 最新可用基金份额 − 周期起点最近可用交易日基金份额
- 自选区间周期 = 止日（或之前最近份额披露日）的基金份额 − 起日（或之前最近份额披露日）的基金份额；所选日期无数据时自动回退到最近交易日
- 估算净申购/赎回金额 = 份额变化 × 当前ETF价格
- ETF资金轮动按ETF名称与跟踪指数名称归类；同一ETF仅归入一个方向，无法明确识别的归入“其他”
- 重点宽基累计份额 = 该指数全部跟踪ETF（含指数增强、指增产品）的交易所披露份额合计；柱为当日有披露的各指数累计份额合计，自下而上每段高度为该指数当日累计份额（自周期起点逐日累加披露变动）；无起点披露的ETF不计入
- 重点宽基归类以交易所披露的跟踪指数代码为准；无披露代码时按名称模式匹配，并排除标普500、科创创业50、中国A50、港股通50、国证1000等相近名称
- 重点宽基每日增减 = 该指数全部跟踪ETF当日披露的份额变动合计，红柱为净申购、绿柱为净赎回，与累计份额同源（逐日差分）；某ETF当日无披露时其变动不计入当日、跨日差分归入再次披露当日
- 重点宽基科创板股票最新权重占比 = 科创板成分股（688/689 开头）权重之和 ÷ 全部成分股权重之和
- 每日科创板权重占比 = 最新日为实际权重占比；历史每日以该权重为锚、按成分股与指数未复权收盘价相对锚定日的变动回溯估算（Σ最新科创权重×个股收盘/锚定价 ÷ 指数收盘/锚定价），属于最新成分回溯估算，未还原历史调仓与历史自由流通股本变化
- 重点宽基创业板最新权重占比 = 创业板成分股（300/301/302 开头）权重之和 ÷ 全部成分股权重之和；四个指数为沪深300、深证成指（399001）、中证500、中证1000
- **深证成指的限制**：国证指数官网仅公开前十大权重（合计约 23%），完整权重非公开，因此该行的权重占比显示为“—”，不参与平均值；成分股列表与板块只数仍按全量 500 只展示
- 每日创业板权重占比与科创板同口径（最新日为实际权重，历史为价格回溯估算）；两个板块的“跟踪ETF”数量均按交易所披露的跟踪指数代码统计，债券、商品和境外指数不计入
- ETF资金流无法识别具体申购账户，不能据此直接确认是否来自中央汇金、证金或其他国家队机构

## 数据文件

- `data/etf_flow_periods.json`：ETF多周期份额和金额变化
- `data/etf_flow_history.json`：趋势及每日图使用的交易日份额变化
- `data/sse_share_history.json`：上交所日频份额本地缓存
- `data/index_weights.json`：按ETF资金变动重要性动态扩展的官方A股指数成分权重与价格
- `data/stock_price_history.json`：科创板/创业板占比每日回溯使用的成分股、指数未复权收盘价按需缓存；既有日期不覆盖，仅增量补齐缺失交易日
- `data/szse_share_history.json`：深交所官方ETF日频份额历史

## 数据源

- 上交所ETF基金份额：上交所ETF规模数据
- 深交所ETF基金份额：深交所ETF规模数据
- 指数权重：中证指数有限公司（`closeweight` 文件，完整权重）、深圳证券信息有限公司（`sample-detail/download`，仅前十大权重）
- 盘中价格、成交、规模及成分股未复权日线收盘价：腾讯证券行情接口
